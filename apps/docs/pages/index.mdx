# Welcome to UI Library

A modern React component library built with TypeScript, Emotion, and best practices.

## Features

- 🎨 **Beautiful Design**: Modern, clean components with consistent styling
- 🎯 **TypeScript**: Fully typed for excellent developer experience
- 🎭 **Emotion Styling**: CSS-in-JS with theming support
- ♿ **Accessible**: WCAG compliant components
- 📦 **Tree-shakeable**: Optimized bundle size

## Installation

```bash
npm install @ui-library/ui
# or
yarn add @ui-library/ui
# or
pnpm add @ui-library/ui
```

## Quick Start

```tsx
import { Button } from '@ui-library/ui'

function App() {
  return <Button variant="primary">Click me</Button>
}
```
