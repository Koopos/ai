import { Card, Button } from '@ui-library/ui'

# Card

Cards contain content and actions about a single subject.

## Basic Card

<Card>
  <Card.Body>
    <p>This is a simple card with body content.</p>
  </Card.Body>
</Card>

```tsx
<Card>
  <Card.Body>
    <p>This is a simple card with body content.</p>
  </Card.Body>
</Card>
```

## Card with Header

<Card>
  <Card.Header title="Card Title" description="Card description goes here" />
  <Card.Body>
    <p>This is the card body content.</p>
  </Card.Body>
</Card>

```tsx
<Card>
  <Card.Header
    title="Card Title"
    description="Card description goes here"
  />
  <Card.Body>
    <p>This is the card body content.</p>
  </Card.Body>
</Card>
```

## API

### Card

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'default' \| 'bordered' \| 'elevated'` | `'default'` | Card style variant |

### Card.Header

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | - | Card title |
| `description` | `string` | - | Card description |

### Card.Body

Standard div wrapper for card content.

### Card.Footer

Standard div wrapper for card footer actions.
