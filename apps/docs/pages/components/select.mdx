import { Select } from '@ui-library/ui'

# Select

Dropdown select component for choosing from a list of options.

## Basic Usage

<Select
  label="Choose an option"
  options={[
    { value: '1', label: 'Option 1' },
    { value: '2', label: 'Option 2' },
    { value: '3', label: 'Option 3' },
  ]}
/>

```tsx
<Select
  label="Choose an option"
  options={[
    { value: '1', label: 'Option 1' },
    { value: '2', label: 'Option 2' },
    { value: '3', label: 'Option 3' },
  ]}
/>
```

## API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | Select label |
| `options` | `SelectOption[]` | - | Array of options |
| `placeholder` | `string` | - | Placeholder text |
| `error` | `string` | - | Error message to display |
| `helperText` | `string` | - | Helper text to display below select |
| `required` | `boolean` | `false` | Whether field is required |
| `fullWidth` | `boolean` | `false` | Whether select takes full width |
| `disabled` | `boolean` | `false` | Whether select is disabled |

### SelectOption

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | - | Option value |
| `label` | `string` | - | Option label |
| `disabled` | `boolean` | `false` | Whether option is disabled |
