# Flappy Bird - Godot

一个使用 Godot 4.x 引擎制作的经典 Flappy Bird 游戏克隆。

## 功能特性

- **经典玩法**: 点击或按空格键控制小鸟飞行
- **障碍物系统**: 随机生成的管道障碍
- **计分系统**: 穿过管道获得分数
- **最高分记录**: 自动保存最高分
- **UI 系统**: 包含开始界面、游戏界面和结束界面
- **响应式设计**: 自适应窗口大小

## 游戏操作

- **空格键** 或 **鼠标左键**: 跳跃/飞行
- **开始按钮**: 开始游戏
- **重新开始按钮**: 游戏结束后重新开始

## 项目结构

```
flappy-bird/
├── scenes/           # 场景文件
│   ├── main_game.tscn  # 主游戏场景
│   ├── player.tscn     # 玩家（鸟）场景
│   ├── pipe.tscn       # 管道障碍场景
│   ├── ground.tscn     # 地面场景
│   └── ui.tscn         # UI 界面场景
├── scripts/          # 脚本文件
│   ├── main_game.gd    # 主游戏逻辑
│   ├── player.gd       # 玩家控制
│   ├── pipe.gd         # 管道逻辑
│   ├── ground.gd       # 地面逻辑
│   └── ui.gd           # UI 逻辑
├── assets/           # 资源文件（图片、音效等）
├── project.godot     # Godot 项目配置
└── README.md         # 项目说明
```

## 如何运行

1. 确保已安装 Godot 4.x
2. 打开 Godot 项目管理器
3. 点击"导入"按钮，选择 `project.godot` 文件
4. 点击"运行"按钮启动游戏

## 开发说明

### 玩家系统 (Player)
- 使用 CharacterBody2D 实现物理效果
- 重力系统让小鸟自然下落
- 点击时给予向上的速度

### 管道系统 (Pipes)
- 随机生成高度不同的管道
- 使用 StaticBody2D 作为碰撞体
- Area2D 用于检测得分

### 游戏状态管理
- **开始界面**: 显示标题和开始按钮
- **游戏进行**: 显示当前分数
- **游戏结束**: 显示分数、最高分和重新开始按钮
